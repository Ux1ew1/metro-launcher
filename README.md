# Metro Launcher

Ностальгический лаунчер для Android в стиле Windows Phone / Windows 10 Mobile (Kotlin + Jetpack Compose, Android 8.0+).

## Что есть

- **Начальный экран с плитками** 1×1, 2×2, 4×2 и 4×4 на сетке из 4 колонок (или 6, если включить «больше плиток»).
- **Турникет (turnstile)**: при запуске приложения плитки по очереди поворачиваются вокруг левого края экрана, нажатая плитка уходит последней. При возврате они так же въезжают обратно. Та же анимация работает при открытии настроек.
- **Tilt-эффект**: плитка, кнопка или строка списка продавливается в ту сторону, куда нажал палец.
- **Живые плитки**: «Часы» и «Календарь» время от времени переворачиваются.
- **Режим редактирования** (долгое нажатие на плитку): остальные плитки уменьшаются и тускнеют. Плитку можно перетаскивать (у краёв экрана работает автопрокрутка), откреплять и менять ей размер круглыми кнопками.
- **Список приложений** (свайп влево или кнопка-стрелка): группы по буквам, латиница и кириллица. Нажатие на букву открывает сетку для быстрого перехода. Есть поиск и контекстное меню: «закрепить», «о приложении», «удалить».
- **Настройки**: тёмная или светлая тема, 20 акцентных цветов WP8, монохромные значки (Android 13+), обои под полупрозрачными плитками.

## Сборка

1. Откройте папку `MetroLauncher` в Android Studio (Open → выбрать папку) и дождитесь Gradle Sync.
2. Run ▶ на подключённом телефоне или эмуляторе (либо Build → Build APK(s)).
3. На телефоне нажмите «Домой» и выберите Metro Launcher. Или откройте настройки лаунчера и нажмите «сделать лаунчером по умолчанию».

В проекте нет `gradle-wrapper.jar`. Android Studio сама скачает Gradle 8.9. Для сборки из командной строки сначала выполните `gradle wrapper`.

## Подстройка анимаций

Все тайминги и углы собраны в `Animations.kt`, в объекте `Turnstile`. Если плитки поворачиваются не в ту сторону, поменяйте знаки `OUT_ANGLE` и `IN_ANGLE`.

Шрифт Segoe и логотипы Microsoft не используются: вместо них системный Roboto Light и собственная иконка.
